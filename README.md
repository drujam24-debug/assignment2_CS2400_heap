# assignment2_CS2400_heap
Assignment Overview
Build a max-heap using an array representation in Java. This project will help you practice heap construction, removal operations, array-based implementation, and time-complexity analysis.

Total points: 100

Important: Start working on this assignment early.

Required Implementation
In heap.java
Implement max-heap construction using sequential insertions.

Implement max-heap construction using the optimal bottom-up method.

Track the number of swaps required by each construction method.

Implement the max-heap remove method.

Be able to explain the time complexity of both construction methods.

Testing and Output
In testHeap.java
Read the 100 positive, nonduplicate integers from data.txt.

Build a max-heap using sequential insertions.

Write the first 10 array values to the output file.

Write the number of swaps used during heap construction.

Remove 10 elements and write the first 10 values of the resulting array.

Repeat steps 2–5 using the optimal bottom-up construction method.

Follow the required output format shown in the full assignment document.
